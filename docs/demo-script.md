# Demo Video Script (20-30 minutes)

## Phase 1: Intelligence (5 min)
1. Open the Dashboard → next week's forecast occupancy is 55% vs 75% in previous years
2. Drill down: season → month → week, slice by H1/H2
3. Dice: transient guests only + high season → ADR is running low

## Phase 2: Design (8 min)
1. Open the What-if tab
2. Drag the segment-A price slider from $120 up to $132
3. M1 reruns → transient demand forecast drops → M2 re-solves → RevPAR changes
4. Try option 2: enter a 40-room group at $80 → M2 recommends 30 rooms

## Phase 3: Choice (5 min)
1. Side-by-side scenario comparison table
2. Goal-seeking: "what segment-A price is needed to reach RevPAR $85?"
3. Pick an option + note the reason

## Phase 4: Implementation (5 min)
1. Open the Tracking tab → compare actual vs plan
2. Back to the Dashboard → the loop closes

## Model Catalog (5 min)
1. Open the Model Catalog tab
2. Show the registry: M1, M2, M3 + metadata + versions
3. Point out the 6 MBMS capabilities as they appear in the app
