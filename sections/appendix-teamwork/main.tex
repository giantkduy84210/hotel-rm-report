\begin{guide}
  \guidepart{Content to include --- REQUIRED BY THE PROJECT DESCRIPTION}
  The project description requires the final report to contain a teamwork report covering
  the teamwork activities and the contribution of each member to the project.
  \begin{itemize}
    \item Group formation: group number, members, role assignment, group agreement
    \item Working environment: Git repository, CI, communication channels, meeting cadence
    \item Contribution table: each member's main responsibilities and approximate share (must sum to 100\%)
    \item Milestones: key phases of the project and who did what
    \item Fill in the real contributions --- then delete this guide box
  \end{itemize}
\end{guide}
